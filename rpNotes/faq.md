# FAQ

## The study guides are detailed and take a long time to read. Won't that mean I never finish the main training?

Decouple **generating** the guide from **fully reading** it.

- Keep generating a guide right after each page — it costs nothing extra, the code is read anyway while it's fresh.
- In the moment, only read the **Snapshot** and the **Cheat Sheet** (2-3 min). That's enough to do the `tdl` exercise. Skip the full Concepts "In Production"/Mistakes tables and skip the **Rebuild Challenge** per page.
- The Rebuild Challenge was never meant to run every page — `prompt.md`'s own usage table says "once per module, not every page."
- Batch the deep-dive: pick one weekly slot (or end of each module) to go back through Concepts/Plumbing/Mistakes for everything done that week, plus one Rebuild Challenge for the module as a whole.

**Tradeoff:** reading deep immediately gives better retention while the exercise is fresh, but at a page-by-page pace it risks stalling the training entirely. A finished training with light per-page notes plus one solid weekly review beats a detailed-but-abandoned one — optimize for finishing; the notes are still there to revisit later.
